# Common / weak / predictable password check

Offline strength-meter upgrade: replaces the old ~150-entry hand-written
`_common_passwords()` / `_common_words()` sets in `tools/utility.cpp` with a
large breach-derived corpus plus normalization that catches *predictable*
passwords, not just exact matches.

This document is self-contained so the **cloud version (`pwmngr2.2.1`)** — whose
`tools/utility.cpp` / `tools/utility.h` are currently byte-identical to
pw-windows' pre-change versions — can adopt the same feature.

---

## What it does

| Signal | Examples caught |
|---|---|
| Exact common/breached password (case-insensitive) | `password`, `123456`, `qwerty` |
| Leetspeak normalization (`@4€3601!$57+2` → letters), `1`→`i`/`l` both tried | `P@ssw0rd`, `passw0rd`, `l3tm31n` |
| Reversed common password | `drowssap` |
| Dictionary base word after stripping edge digits/symbols | `dragon99!`, `maggie21`, `Sunshine2024`, `elephant123` |
| Repeat-collapsed base word (`3+` run → `1`) | `passworddd` |
| Keyboard walk (≥4 adjacent keys, rows/columns, forward+reverse) | `qwerty`, `asdfgh`, `1qaz2wsx`, `zxcvbnm` |

Strong passphrases are **not** flagged (`correcthorsebatterystaple` is not a
single dictionary word, so it stays strong). Lookups are exact binary searches —
**no false positives** from the list itself.

The meter (`DrawStrengthMeter`) now surfaces the common-password / dictionary /
keyboard-walk reasons, which were previously computed but never shown.

## Data source & generation

- **Source:** [SecLists](https://github.com/danielmiessler/SecLists) (MIT) —
  `Passwords/Common-Credentials/xato-net-10-million-passwords-100000.txt`
  (frequency-ranked across breaches, subsumes the rockyou top entries).
- **Generator:** `gen_wordlist.py` (mirrors the existing `gen_favicons.py`
  pattern). Downloads the list, lowercases / ASCII-filters / dedupes / length-
  bounds it, merges the original curated lists so nothing regresses, sorts by
  unsigned-byte order, and emits `tools/common_passwords_data.h` with two blobs:
  - `g_common_pw_blob` — 96,518 common passwords
  - `g_common_word_blob` — 43,787 dictionary base words / names

```sh
python gen_wordlist.py        # network needed at BUILD time only; runtime is fully offline
```

The generated header is ~6.8 MB (on par with the existing `icons/mdi_font_data.h`).
It is committed like the other `*_data.h` headers. The script caches the
download to `_wordlist_tmp.txt` (safe to delete / gitignore).

### Scaling coverage later
Edit `LIST_URL` in `gen_wordlist.py` and re-run:
- `...top-1000000.txt` → top-1M, **but** the byte-array header becomes ~50 MB
  (chokes IntelliSense, bloats the repo). If you want 1M, switch the header to a
  Windows `RCDATA` resource or a bloom filter instead of a byte array.
- `.../Leaked-Databases/rockyou-75.txt` → pure rockyou (~59k).

100k + the heuristics is the sweet spot: the 100k→1M tail is passwords seen only
a handful of times across all breaches (already "uncommon"), and predictable
variants are caught by normalization regardless of list size.

## Notes / tradeoffs

- **Build-time network only.** Generating the header needs the internet once;
  the shipped app performs the check entirely offline — consistent with
  pw-windows' offline-only design and complementary to the opt-in HIBP check.
- **Memory:** the two blobs are split into `string_view` indexes lazily on first
  use (~2.2 MB total, built once, UI-thread only). The blobs themselves live in
  read-only data.
- **Performance:** `analyze_password` runs per-frame while typing; each call does
  a handful of `O(log n)` binary searches + small string normalizations —
  negligible.
- **Encoding:** non-ASCII source entries are dropped (the check is byte-wise and
  ASCII-oriented); these are a tiny fraction and not "common English words".
- **`1` ambiguity:** leetspeak tries both `1`→`i` and `1`→`l`. Other glyphs use a
  single canonical mapping; popular leet passwords (e.g. `p@ssw0rd`) are also in
  the list verbatim, so they match exactly regardless.

## Appendix A — detection block (`tools/utility.cpp`)

Paste between `_has_simple_sequence(...)` and `analyze_password(...)`:

```cpp
    // ---- Common passwords & dictionary words (data-driven) ----
    // Backed by large sorted blobs in common_passwords_data.h. Each blob is
    // '\n'-separated and sorted by unsigned-byte order, so we split it into
    // string_views once (lazily) and binary-search. Regenerate via gen_wordlist.py.

    static std::vector<std::string_view> _build_index(
        const unsigned char* blob, unsigned long len)
    {
        std::vector<std::string_view> v;
        const char* p = reinterpret_cast<const char*>(blob);
        size_t start = 0;
        for (size_t i = 0; i <= (size_t)len; ++i)
        {
            if (i == (size_t)len || p[i] == '\n')
            {
                if (i > start) v.emplace_back(p + start, i - start);
                start = i + 1;
            }
        }
        return v;
    }

    static bool _in_common_pw(std::string_view key)
    {
        static const std::vector<std::string_view> idx =
            _build_index(g_common_pw_blob, g_common_pw_blob_len);
        return std::binary_search(idx.begin(), idx.end(), key);
    }

    static bool _in_common_word(std::string_view key)
    {
        static const std::vector<std::string_view> idx =
            _build_index(g_common_word_blob, g_common_word_blob_len);
        return std::binary_search(idx.begin(), idx.end(), key);
    }

    static std::string _to_lower(const std::string& s)
    {
        std::string r = s;
        std::transform(r.begin(), r.end(), r.begin(),
            [](unsigned char c) { return (char)std::tolower(c); });
        return r;
    }

    static std::string _reverse(const std::string& s)
    {
        return std::string(s.rbegin(), s.rend());
    }

    // Map common leetspeak substitutions back to letters: "pa$$w0rd" -> "password".
    // '1' is ambiguous (i vs l); callers try both via _matches_with_leet.
    static std::string _deleet(const std::string& s, bool oneToL)
    {
        std::string r; r.reserve(s.size());
        for (unsigned char c : s)
        {
            char m;
            switch (c)
            {
            case '@': case '4':           m = 'a'; break;
            case '8':                     m = 'b'; break;
            case '(': case '{': case '<': m = 'c'; break;
            case '3':                     m = 'e'; break;
            case '6': case '9':           m = 'g'; break;
            case '#':                     m = 'h'; break;
            case '1':                     m = oneToL ? 'l' : 'i'; break;
            case '!': case '|':           m = 'i'; break;
            case '0':                     m = 'o'; break;
            case '$': case '5':           m = 's'; break;
            case '7': case '+':           m = 't'; break;
            case '2':                     m = 'z'; break;
            default:                      m = (char)std::tolower(c); break;
            }
            r += m;
        }
        return r;
    }

    // Collapse runs of 3+ identical chars to one ("passworddd" -> "password"),
    // leaving singles and doubles intact ("feel" stays "feel").
    static std::string _collapse_repeats(const std::string& s)
    {
        std::string r; r.reserve(s.size());
        size_t i = 0;
        while (i < s.size())
        {
            char c = s[i];
            size_t j = i;
            while (j < s.size() && s[j] == c) ++j;
            r += c;
            if (j - i == 2) r += c;
            i = j;
        }
        return r;
    }

    // True if `word`, or a de-leetspeaked variant of it, satisfies `pred`.
    static bool _matches_with_leet(const std::string& word,
                                   bool (*pred)(std::string_view))
    {
        if (pred(word)) return true;
        std::string a = _deleet(word, false); // 1 -> i
        if (a != word && pred(a)) return true;
        std::string b = _deleet(word, true);  // 1 -> l
        if (b != a && b != word && pred(b)) return true;
        return false;
    }

    // Strip leading/trailing non-alpha to extract a base word: "maggie21" -> "maggie".
    static std::string _extract_base_word(const std::string& pw)
    {
        std::string low = _to_lower(pw);
        size_t end = low.size();
        while (end > 0 && !std::isalpha((unsigned char)low[end - 1])) --end;
        size_t start = 0;
        while (start < end && !std::isalpha((unsigned char)low[start])) ++start;
        if (end - start < 3) return ""; // too short to be a word
        return low.substr(start, end - start);
    }

    // Detect keyboard walks like "qwerty", "asdfgh", "1qaz2wsx" (>=4 adjacent keys).
    static bool _is_keyboard_walk(const std::string& s)
    {
        if (s.size() < 4) return false;
        std::string low = _to_lower(s);
        static const char* rows[] = {
            "qwertyuiop", "asdfghjkl", "zxcvbnm", "1234567890",
            "1qaz2wsx3edc4rfv5tgb6yhn7ujm8ik9ol0p", // vertical columns
            "qazwsxedcrfvtgbyhnujmikolp",           // diagonal-ish
        };
        for (const char* row : rows)
        {
            std::string fwd(row);
            std::string rev(fwd.rbegin(), fwd.rend());
            for (size_t i = 0; i + 4 <= low.size(); ++i)
            {
                std::string w = low.substr(i, 4);
                if (fwd.find(w) != std::string::npos ||
                    rev.find(w) != std::string::npos)
                    return true;
            }
        }
        return false;
    }

    static bool _is_common_password(const std::string& pw)
    {
        std::string low = _to_lower(pw);
        if (_matches_with_leet(low, &_in_common_pw)) return true;
        std::string rev = _reverse(low);             // "drowssap" -> "password"
        if (rev != low && _in_common_pw(rev)) return true;
        return false;
    }

    static bool _is_dictionary_based(const std::string& pw)
    {
        std::string base = _extract_base_word(pw);
        if (base.size() < 3) return false;
        if (_matches_with_leet(base, &_in_common_word)) return true;
        if (_matches_with_leet(base, &_in_common_pw))   return true;
        std::string col = _collapse_repeats(base);   // "passworddd" -> "password"
        if (col != base && col.size() >= 3 &&
            (_in_common_word(col) || _in_common_pw(col))) return true;
        return false;
    }
```
